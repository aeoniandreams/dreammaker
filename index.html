사용 방법

기본 사용법
  1. 캐릭터 정보 표를 클릭해 내용을 직접 입력하세요. 처음에는 2칸 x 10줄 기본 틀이 들어 있고, 행·열 추가, 셀 합치기, 배경색 같은 표 도구로 캐릭터마다 다른 모양으로 바꿀 수 있어요.
  2. 윗주: 글자를 드래그한 뒤 윗주 버튼을 누르고 내용을 입력하면 그 글자 위에 작게 표시돼요(후리가나 등).
  3. 주석은 {{주석 내용}}을 넣으면 자동으로 완성됩니다.
    {{[스포일러]|주석내용}}으로 텍스트 주석을 넣을 수 있어요!
  4. 우측 미리보기는 입력 시 자동 갱신됩니다. 수동 갱신은 코드 갱신을 누르세요.
  5. 티스토리 글쓰기 → 기본모드 → HTML 모드에서 코드를 붙여 넣으면 끝!
  6. 작업 내용은 저장 버튼으로 JSON 파일로 보관하세요.
  7. 내 작업에서는 이름을 붙여 이 브라우저에 여러 작업을 저장하고 골라서 불러올 수 있어요. 다른 기기와는 공유되지 않아요.
  8. JSON 파일이 없어도 이미 만든 코드를 HTML 불러오기에 붙여 넣으면 작업 내용을 되살릴 수 있어요.
TIP
  1. 본문 에디터의 블록은 드래그하여 순서를 바꿀 수 있습니다.
  2. 아이콘이 표시되지 않으면 티스토리 스킨 HTML의 </body> 바로 위에 Ionicons 스크립트를 추가해 주세요.
  3. HTML 모드로 글을 저장한 후 수정할 때는 사이트를 이용해주세요. 티스토리 에디터 내에서 기본 모드로 전환한 후 저장 시 코드의 일부분이 사라집니다

내 작업

작업에 이름을 붙여 저장해 두고, 목록에서 골라 불러올 수 있어요. 구글 로그인을 하지 않으면 이 브라우저에만 저장되어 다른 기기와 공유되지 않고 브라우저 데이터를 지우면 사라져요. 중요한 작업은 저장 버튼으로 JSON 파일에도 백업해 두세요.

HTML 코드로 불러오기

생성기로 만든 코드를 붙여 넣으면 작업 내용을 복원해요. 현재 작업 내용은 붙여 넣은 코드로 바뀌니, 필요하면 먼저 저장해 두세요.
